# 微信工程配置逐项说明

本文档逐项解释 `project.config.json` 与 `project.private.config.json` 中现有字段含义。  
说明基于当前仓库文件内容，重点偏向实际开发影响。

## 一、`project.config.json`（团队共享配置）

### 根级字段

- `miniprogramRoot`
  - 小程序源码目录（相对工程根目录）。
  - 当前为 `dist/`，表示微信开发者工具直接加载 Taro 构建产物。

- `projectname`
  - 开发者工具中显示的项目名称。

- `description`
  - 项目描述信息，主要用于工具展示。

- `appid`
  - 小程序 AppID。
  - 影响登录、上传、真机预览、发布等核心能力，必须与目标小程序一致。

- `setting`
  - 编译、压缩、校验等核心行为配置集合。

- `compileType`
  - 项目类型。
  - `miniprogram` 表示小程序项目（非小游戏等）。

- `simulatorPluginLibVersion`
  - 模拟器插件库版本配置映射（当前空对象，表示未额外指定）。

- `packOptions`
  - 打包包含/忽略规则。

- `editorSetting`
  - 编辑器相关设置（当前为空对象）。

- `libVersion`
  - 使用的基础库版本（工具里可切换），影响 API 可用性与兼容性。

### `setting` 字段

- `urlCheck`
  - 是否校验 request/socket/upload/download 的合法域名。
  - `true` 时更接近线上规则。

- `es6`
  - ES6 转 ES5 相关旧选项（历史兼容项）。

- `enhance`
  - 增强编译能力开关（与工具能力相关）。

- `compileHotReLoad`
  - 编译热重载。开启后保存代码更快反馈。

- `postcss`
  - 启用样式后处理能力（如自动补全等）。

- `minified`
  - 是否压缩代码（通常影响体积与可读性）。

- `compileWorklet`
  - Worklet 编译相关能力开关。

- `uglifyFileName`
  - 压缩/构建时处理文件名相关策略（工具控制）。

- `uploadWithSourceMap`
  - 上传代码时是否携带 SourceMap（用于线上问题定位）。

- `packNpmManually`
  - 是否手动管理 npm 打包。

- `packNpmRelationList`
  - 手动 npm 打包时的依赖关系配置列表。

- `minifyWXSS`
  - 是否压缩 WXSS。

- `minifyWXML`
  - 是否压缩 WXML。

- `localPlugins`
  - 是否启用本地插件能力。

- `disableUseStrict`
  - 是否禁用严格模式注入（`"use strict"` 相关）。

- `useCompilerPlugins`
  - 是否启用编译插件机制。

- `condition`
  - 条件编译/编译条件相关开关（工具配置项）。

- `swc`
  - 是否启用 SWC 编译链路。

- `disableSWC`
  - 是否禁用 SWC。与 `swc` 组合决定最终行为。

- `babelSetting`
  - Babel 细项配置。

### `setting.babelSetting` 字段

- `ignore`
  - Babel 忽略处理路径列表。

- `disablePlugins`
  - 禁用的 Babel 插件列表。

- `outputPath`
  - Babel 输出路径配置（为空表示默认策略）。

### `packOptions` 字段

- `ignore`
  - 打包时忽略路径/规则。

- `include`
  - 打包时强制包含路径/规则。

## 二、`project.private.config.json`（个人本地配置）

这个文件用于“当前机器/当前开发者”的私有偏好，一般不建议团队强同步。

### 根级字段

- `libVersion`
  - 当前开发者本地调试使用的基础库版本。

- `projectname`
  - 本地工具显示名称（与共享配置可一致）。

- `setting`
  - 本地调试行为开关集合。

### `setting` 字段

- `urlCheck`
  - 本地是否校验合法域名。

- `coverView`
  - CoverView 能力相关编译/调试选项。

- `lazyloadPlaceholderEnable`
  - 懒加载占位能力开关。

- `skylineRenderEnable`
  - Skyline 渲染引擎相关开关。

- `preloadBackgroundData`
  - 后台预加载数据能力开关。

- `autoAudits`
  - 自动审计（代码质量/规范提示）开关。

- `useApiHook`
  - API Hook 相关能力开关。

- `useApiHostProcess`
  - API Host 进程能力开关。

- `showShadowRootInWxmlPanel`
  - 调试面板中显示 ShadowRoot 相关选项。

- `useStaticServer`
  - 静态服务调试能力开关。

- `useLanDebug`
  - 局域网调试能力开关。

- `showES6CompileOption`
  - 是否在工具中显示 ES6 编译选项。

- `compileHotReLoad`
  - 本地热重载开关（常见个人偏好项）。

- `checkInvalidKey`
  - 检查 WXML/配置无效 key 的校验开关。

- `ignoreDevUnusedFiles`
  - 开发态忽略未使用文件检查，减少噪音提示。

- `bigPackageSizeSupport`
  - 大包体支持相关开关。

## 三、为什么不直接在 JSON 文件里逐行写注释

- `project.config.json` 与 `project.private.config.json` 需要保持 **严格 JSON**。
- JSON 标准不支持 `//` 或 `/* */` 注释。
- 直接在文件里写注释可能导致微信开发者工具解析失败或配置异常。
