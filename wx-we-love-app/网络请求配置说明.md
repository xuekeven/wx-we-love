# 🌐 网络请求配置说明

## ❌ 问题
```
http://localhost:3000 不在以下 request 合法域名列表中
```

## ✅ 解决方案

### 方案 1: 开发阶段（推荐）⭐⭐⭐

**在微信开发者工具中关闭域名校验：**

1. 打开微信开发者工具
2. 点击右上角 **"详情"** 按钮
3. 选择 **"本地设置"** 标签
4. 勾选 ✅ **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**
5. 刷新页面

**截图位置：**
```
微信开发者工具
└── 右上角"详情"
    └── "本地设置"
        └── [✓] 不校验合法域名...
```

### 方案 2: 生产环境配置

当您准备发布小程序时，需要在小程序后台配置合法域名：

#### 步骤：

1. **登录微信公众平台**
   - 访问: https://mp.weixin.qq.com/
   - 使用管理员账号登录

2. **进入开发管理**
   ```
   左侧菜单
   └── 开发
       └── 开发管理
           └── 开发设置
               └── 服务器域名
   ```

3. **配置 request 合法域名**
   - 点击"修改"按钮
   - 在 **request合法域名** 中添加：
     ```
     https://www.kaitool.top
     ```
   - 点击"保存并提交"

#### ⚠️ 注意事项：

1. **域名要求**
   - ✅ 必须是 https:// 协议（生产环境）
   - ✅ 必须有备案的域名
   - ❌ 不能使用 IP 地址（正式发布）
   - ❌ 不能使用 localhost

2. **生产环境配置**
   ```
   ✅ 推荐: https://www.kaitool.top
   ```

3. **配置生效时间**
   - 配置后需要等待几分钟生效
   - 每月只能修改 5 次

## 🔧 Nginx 配置示例（HTTPS）

```nginx
server {
    listen 443 ssl;
    server_name www.kaitool.top;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://127.0.0.1:4000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 🐛 常见问题

### Q1: 关闭域名校验后还是报错？
**A:** 
1. 确认是否勾选了选项
2. 刷新页面或重启开发者工具
3. 检查后端是否正常运行: `curl http://localhost:4000/health`

### Q2: 能否在正式版使用 IP 地址？
**A:** 
- ❌ 不可以，正式发布必须使用 HTTPS 域名
- ✅ 开发和测试阶段可以关闭校验
- ✅ 正式发布使用 `https://www.kaitool.top`

### Q3: 每月只能修改 5 次域名怎么办？
**A:**
- 提前规划好域名
- 一次性配置多个可能用到的域名

### Q4: 本地调试时后端在局域网另一台机器？
**A:**
修改 `src/config.js`:
```javascript
development: {
  apiBaseUrl: 'http://192.168.1.100:4000'  // 局域网 IP
}
```
