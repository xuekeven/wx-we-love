# 💻 本地调试指南

## 🎯 快速开始

本地调试需要同时运行前端和后端服务。

### 第一步：启动后端服务

打开第一个终端窗口：

```bash
# 进入后端目录
cd wx-we-love-api

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

**看到以下信息说明后端启动成功：**
```
🚀 Server is running on port 4000
📝 Environment: development
🌐 API Base URL: http://localhost:4000/api
✅ Database connection established successfully
```

验证后端服务：打开浏览器访问 http://localhost:4000/health

### 第二步：启动前端服务

打开第二个终端窗口：

```bash
# 进入前端目录
cd wx-we-love-app

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev:weapp
```

**看到编译成功信息后：**
1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择：`wx-we-love-app`
4. AppID：选择"测试号"（或填入你的AppID）
5. 点击"导入"

## 🔧 API地址配置说明

### 当前配置

**本地开发环境** (`config/dev.ts`)：
```typescript
API_BASE_URL: '"http://localhost:4000"'  // 指向本地后端
```

**生产环境** (`config/prod.ts`)：
```typescript
API_BASE_URL: '"https://www.kaitool.top"'  // 指向服务器
```

### 如何切换环境

**方式一：修改配置文件（推荐）**

本地调试时（默认已配置）：
```bash
# config/dev.ts
API_BASE_URL: '"http://localhost:4000"'
```

部署到服务器时：
```bash
# 使用生产环境构建
npm run build:weapp
```

**方式二：临时修改端口**

如果后端使用其他端口（如4001），修改 `config/dev.ts`：
```typescript
API_BASE_URL: '"http://localhost:4001"'
```

## 📱 微信开发者工具配置

### 1. 跨域和网络请求设置

在微信开发者工具中：

1. 点击右上角"详情"
2. 找到"本地设置"
3. 勾选以下选项：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
   - ✅ **启用调试模式**

### 2. 查看网络请求

开发者工具底部"Network"面板可以查看所有API请求：
- 请求地址
- 请求参数
- 响应数据
- 耗时统计

### 3. 查看控制台日志

"Console"面板可以查看：
- `console.log` 输出
- 错误信息
- 网络错误

## 🐛 常见问题

### Q1: 前端显示"网络错误"

**检查清单：**
1. ✅ 后端服务是否正常运行？
   ```bash
   # 访问这个地址应该返回JSON数据
   curl http://localhost:4000/health
   ```

2. ✅ 端口是否被占用？
   ```bash
   # 查看4000端口
   lsof -i :4000
   ```

3. ✅ 微信开发者工具是否关闭了域名校验？

4. ✅ API地址配置是否正确？
   检查 `config/dev.ts` 中的 `API_BASE_URL`

### Q2: 修改代码后没有生效

**前端代码修改：**
- Taro会自动热更新
- 如果没有更新，在微信开发者工具中点击"编译"

**后端代码修改：**
- 使用 `npm run dev`（nodemon会自动重启）
- 如果使用 `npm start`，需要手动重启

### Q3: 端口4000被占用

**查找占用进程：**
```bash
lsof -i :4000
# 或
netstat -vanp tcp | grep 4000
```

**方法一：杀死占用进程**
```bash
kill -9 <PID>
```

**方法二：更换端口**

修改后端端口（`wx-we-love-api/.env`）：
```env
PORT=4001
```

同时修改前端配置（`wx-we-love-app/config/dev.ts`）：
```typescript
API_BASE_URL: '"http://localhost:4001"'
```

### Q4: 数据修改后丢失

数据存储在 MySQL 数据库中，重启不会丢失。
如数据库未连接，请检查 `.env` 配置文件。

### Q5: 微信开发者工具无法打开项目

**检查：**
1. 是否安装了微信开发者工具？
   - 下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

2. 项目目录是否正确？
   - 应该选择 `wx-we-love-app` 整个文件夹
   - 不是 `src` 子目录

3. 是否已编译？
   - 先在终端运行 `npm run dev:weapp`
   - 等待编译完成后再打开开发者工具

## 🔍 调试技巧

### 1. 查看API请求详情

在前端代码中添加日志：

```typescript
// src/utils/request.ts
export const request = async (options: RequestOptions) => {
  console.log('发送请求:', options)
  
  const res = await Taro.request({...})
  
  console.log('响应数据:', res)
  return res.data
}
```

### 2. 测试后端API

使用curl测试：
```bash
# 测试健康检查
curl http://localhost:4000/health

# 测试用户信息
curl http://localhost:4000/api/user/info

# 测试心愿清单
curl http://localhost:4000/api/wishlist

# POST请求示例
curl -X POST http://localhost:4000/api/wishlist \
  -H "Content-Type: application/json" \
  -d '{"content":"测试心愿"}'
```

### 3. 使用Postman测试API

1. 下载Postman: https://www.postman.com/downloads/
2. 创建新请求
3. 输入地址：`http://localhost:4000/api/user/info`
4. 点击"Send"查看响应

### 4. 实时查看后端日志

后端会输出请求日志：
```
[2025-04-23T10:30:00.000Z] GET /api/user/info
[2025-04-23T10:30:01.000Z] GET /api/wishlist
```

### 5. Chrome DevTools 调试H5版本

```bash
# 启动H5版本
npm run dev:h5
```

然后在Chrome中打开 http://localhost:10086，可以使用完整的DevTools。

## 🚀 准备部署到服务器

调试完成后，部署前需要：

1. **构建生产版本**
   ```bash
   npm run build:weapp
   ```

2. **上传后端到服务器**
   ```bash
   scp -r wx-we-love-api root@www.kaitool.top:/root/
   ```

3. **在小程序后台配置服务器域名**
   - request合法域名：`https://www.kaitool.top`

## 💡 开发建议

1. **先开发单个功能**：完成一个功能页面后再开发下一个
2. **频繁测试**：每次修改后立即测试
3. **查看日志**：遇到问题先查看控制台和Network
4. **使用Git**：每完成一个功能就提交代码
5. **数据隔离**：本地和服务器使用不同的数据
