## 🔄 SVG 转 PNG 方法

### 在线转换（最简单）
1. 访问: https://svgtopng.com/
2. 上传 SVG 文件或粘贴代码
3. 设置尺寸为 81x81
4. 下载 PNG

### 使用命令行（需要安装 ImageMagick）
```bash
# 安装 ImageMagick
brew install imagemagick

# 转换 SVG 到 PNG
convert -background none -size 81x81 home.svg home.png
```

## 💡 设计建议

### 视觉风格
- ✨ 简约现代
- 💕 圆润可爱
- 🎨 线条流畅
- 🌸 符合情侣主题

### 色彩搭配
- 未选中态要低调（灰色）
- 选中态要醒目（粉色）
- 保持视觉统一性

### 细节优化
- 线条粗细一致（3-4px）
- 图标居中对齐
- 适当留白
- 测试不同背景
