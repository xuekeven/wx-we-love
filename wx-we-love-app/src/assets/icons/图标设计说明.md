# 小程序图标

底部导航使用 81 × 81 像素的透明 PNG。未选中颜色为 `#756960`，选中颜色为 `#94605A`，路径在 `src/app.config.ts` 中配置。

| 页面 | 图案 | 文件 |
| --- | --- | --- |
| 首页 | 爱心 | `home.png`、`home-active.png` |
| 瞬间 | 相机 | `moment.png`、`moment-active.png` |
| 我的 | 用户 | `my.png`、`my-active.png` |

首页入口使用同尺寸的透明 PNG，分别为 `diary.png`、`anniversary.png` 和 `cycle.png`。
