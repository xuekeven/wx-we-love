# 🚀 后端启动说明

## 快速启动

### 1. 安装依赖
```bash
cd wx-we-love-api
npm install
```

### 2. 启动服务
```bash
# 开发模式（自动重启）
npm run dev

# 或者生产模式
npm start
```

### 3. 验证服务
打开浏览器访问：
- 主页: http://localhost:4000
- 健康检查: http://localhost:4000/health

看到以下信息说明启动成功：
```json
{
  "message": "💕 Welcome to We Love API",
  "version": "1.0.0",
  "endpoints": {...}
}
```

## 配置服务器地址

服务器域名：`www.kaitool.top`

### 方法1: 直接在服务器运行
```bash
# 1. 上传代码到服务器
scp -r wx-we-love-api root@www.kaitool.top:/root/

# 2. SSH登录服务器
ssh root@www.kaitool.top

# 3. 进入项目目录
cd /root/wx-we-love-api

# 4. 安装依赖
npm install

# 5. 使用PM2启动（推荐）
npm install -g pm2
pm2 start src/index.js --name wx-we-love-api
pm2 save
pm2 startup

# 6. 查看日志
pm2 logs wx-we-love-api
```

### 方法2: 使用Docker（推荐）
```bash
# 创建Dockerfile
cat > Dockerfile << 'EOF'
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 4000
CMD ["node", "src/index.js"]
EOF

# 构建镜像
docker build -t wx-we-love-api .

# 运行容器
docker run -d -p 4000:4000 --name wx-we-love-api wx-we-love-api
```

## 数据库配置（可选）

当前使用内存数据库，数据在重启后会丢失。

如需持久化，配置MySQL：

1. 修改 `.env` 文件：
```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=wx_we_love
DB_USER=root
DB_PASSWORD=your_password
```

2. 创建数据库：
```sql
CREATE DATABASE wx_we_love CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 防火墙设置

确保服务器开放4000端口：
```bash
# CentOS/RHEL
firewall-cmd --permanent --add-port=4000/tcp
firewall-cmd --reload

# Ubuntu/Debian
ufw allow 4000/tcp
```

## Nginx反向代理（推荐）

配置 HTTPS 反向代理，对应前端请求 `https://www.kaitool.top`：

```nginx
server {
    listen 443 ssl;
    server_name www.kaitool.top;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:4000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 80;
    server_name www.kaitool.top;
    return 301 https://$host$request_uri;
}
```

## 常见问题

### Q: 端口被占用
```bash
# 查找占用4000端口的进程
lsof -i :4000
# 或
netstat -tlnp | grep 4000

# 杀死进程
kill -9 <PID>
```

### Q: npm install失败
```bash
# 清除缓存重试
npm cache clean --force
npm install
```

### Q: 前端无法连接
检查：
1. 后端服务是否正常运行
2. 防火墙是否开放端口
3. 前端配置的API地址是否正确（`https://www.kaitool.top`）
