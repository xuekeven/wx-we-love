# 🚀 服务器部署指南

## 📋 部署前准备

### 1. 服务器要求

- **操作系统**: Linux (推荐 Ubuntu 20.04+ 或 CentOS 7+)
- **Node.js**: v16+ 
- **内存**: 至少 1GB
- **磁盘**: 至少 10GB

### 2. 需要准备的信息

- 服务器IP地址
- 服务器SSH登录凭证
- 微信小程序 AppID 和 AppSecret
- 数据库密码（如果使用MySQL）

---

## 🔧 第一步：服务器环境准备

### 1.1 连接服务器

```bash
ssh root@your-server-ip
```

### 1.2 更新系统

```bash
# Ubuntu/Debian
apt update && apt upgrade -y

# CentOS
yum update -y
```

### 1.3 安装 Node.js

```bash
# 使用 NodeSource 安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs

# 验证安装
node -v
npm -v
```

### 1.4 安装 PM2（进程管理器）

```bash
npm install -g pm2
```

### 1.5 安装 MySQL（推荐）或使用 SQLite

**选项A：安装MySQL（推荐用于生产环境）**

```bash
# Ubuntu/Debian
apt install -y mysql-server

# CentOS
yum install -y mysql-server
systemctl start mysqld
systemctl enable mysqld

# 安全配置
mysql_secure_installation
```

**创建数据库：**

```bash
mysql -u root -p
```

```sql
CREATE DATABASE wx_we_love CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'wx_love_user'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON wx_we_love.* TO 'wx_love_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

**选项B：使用SQLite（简单但不推荐生产环境）**

SQLite无需额外安装，但需要确保有写入权限。

## 📦 第二步：部署后端代码

### 2.1 创建项目目录

```bash
# 创建目录
mkdir -p /var/www/wx-we-love-api

# 进入目录
cd /var/www/wx-we-love-api

# 验证目录已创建
pwd
# 应该显示：/var/www/wx-we-love-api
```

### 2.2 上传代码

**方式一：使用 Git（推荐）**

```bash
# 安装 Git（如果还没有）
apt install -y git  # Ubuntu/Debian
# 或
yum install -y git  # CentOS

# 进入项目目录
cd /var/www/wx-we-love-api

# 克隆项目（替换为你的仓库地址）
git clone your-repo-url .

# 或者如果已经有代码，直接克隆到当前目录
git clone your-repo-url /var/www/wx-we-love-api
```

**方式二：使用 SCP 上传（从本地电脑上传）**

在**本地电脑**的终端执行：

```bash
# 进入项目目录
cd /path/to/wx-we-love-api

# 上传整个项目目录
scp -r . root@your-server-ip:/var/www/wx-we-love-api/

# 或者只上传必要的文件（排除 node_modules）
rsync -av --exclude 'node_modules' --exclude '.git' \
  ./ root@your-server-ip:/var/www/wx-we-love-api/
```

**方式三：使用 SFTP 工具**

使用 FileZilla、WinSCP 等工具：
- 主机：`your-server-ip`
- 用户名：`root`
- 端口：`22`
- 上传到：`/var/www/wx-we-love-api/`

### 2.3 验证文件已上传

```bash
cd /var/www/wx-we-love-api
ls -la

# 应该看到以下文件：
# - package.json
# - src/
# - ecosystem.config.js
# 等
```

### 2.4 安装依赖

```bash
cd /var/www/wx-we-love-api
npm install --production
```

## ⚙️ 第三步：配置环境变量

### 3.1 创建 .env 文件

```bash
cd /var/www/wx-we-love-api
nano .env
```

### 3.2 配置内容

```env
# 服务器配置
NODE_ENV=production
PORT=4000

# 数据库配置（MySQL）
DB_HOST=localhost
DB_PORT=3306
DB_NAME=wx_we_love
DB_USER=wx_love_user
DB_PASSWORD=your_strong_password

# 如果使用SQLite，注释掉上面的MySQL配置，使用：
# SQLITE_STORAGE=/var/www/wx-we-love-api/database.sqlite

# JWT密钥（请使用强密码）
JWT_SECRET=your_very_strong_jwt_secret_key_here

# 微信小程序配置
WX_APPID=your_wechat_miniprogram_appid
WX_SECRET=your_wechat_miniprogram_secret
```

### 3.3 设置文件权限

```bash
chmod 600 .env  # 只有所有者可读写
```

## 🗄️ 第四步：初始化数据库

### 4.1 测试数据库连接

**⚠️ 注意：必须先完成第二步（上传代码），才能执行此步骤！**

```bash
# 确保在项目目录中
```

**如果提示目录不存在：**

```bash

```

## 🚀 第五步：使用 PM2 启动服务

### 5.1 创建 PM2 配置文件

项目已包含 `ecosystem.config.js`，如果不存在，创建：

```bash
cd /var/www/wx-we-love-api
nano ecosystem.config.js
```

```javascript
module.exports = {
  apps: [{
    name: 'wx-we-love-api',
    script: './src/index.js',
    instances: 1,
    exec_mode: 'fork',
    env: {
      NODE_ENV: 'production',
      PORT: 4000
    },
    error_file: './logs/err.log',
    out_file: './logs/out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
    merge_logs: true,
    autorestart: true,
    watch: false,
    max_memory_restart: '500M'
  }]
}
```

### 5.2 创建日志目录

```bash
mkdir -p logs
```

### 5.3 启动服务

```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup  # 设置开机自启
```

### 5.4 常用 PM2 命令

```bash
pm2 list              # 查看运行状态
pm2 logs              # 查看日志
pm2 restart wx-we-love-api  # 重启服务
pm2 stop wx-we-love-api     # 停止服务
pm2 delete wx-we-love-api   # 删除服务
```

## 🔒 第六步：配置防火墙

### 6.1 开放端口

```bash
# Ubuntu (ufw)
ufw allow 4000/tcp
ufw enable

# CentOS (firewalld)
firewall-cmd --permanent --add-port=4000/tcp
firewall-cmd --reload

# 或使用 iptables
iptables -A INPUT -p tcp --dport 4000 -j ACCEPT
```

### 6.2 测试服务

```bash
curl http://localhost:4000/health
```

如果返回 JSON 数据，说明服务正常运行。

## 🌐 第七步：配置 Nginx 反向代理（可选但推荐）

### 7.1 安装 Nginx

```bash
apt install -y nginx  # Ubuntu/Debian
# 或
yum install -y nginx  # CentOS
```

### 7.2 配置 Nginx

```bash
nano /etc/nginx/sites-available/wx-we-love-api
```

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或使用服务器IP

    location / {
        proxy_pass http://localhost:4000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 7.3 启用配置

```bash
# Ubuntu/Debian
ln -s /etc/nginx/sites-available/wx-we-love-api /etc/nginx/sites-enabled/
nginx -t  # 测试配置
systemctl restart nginx

# CentOS
# 配置文件在 /etc/nginx/conf.d/wx-we-love-api.conf
nginx -t
systemctl restart nginx
```

## 📱 第九步：更新前端配置

### 9.1 修改前端 API 地址

编辑 `wx-we-love-app/src/config.js`:

```javascript
const config = {
  development: {
    apiBaseUrl: 'http://192.168.3.11:4000'  // 本地开发
  },
  production: {
    apiBaseUrl: 'https://your-domain.com'  // 生产环境使用HTTPS
    // 或使用IP: 'http://your-server-ip:4000'
  }
}
```

### 9.2 在微信小程序后台配置域名

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 **开发** → **开发管理** → **开发设置**
3. 在 **服务器域名** 中配置：
   - **request合法域名**: `https://your-domain.com`
   - 点击 **保存并提交**

⚠️ **注意**：
- 必须使用 HTTPS（生产环境）
- 域名需要备案（国内服务器）
- 每月只能修改 5 次

## 🐛 常见问题

### 问题1: 数据库连接失败

**检查：**
- 数据库服务是否启动: `systemctl status mysql`
- 用户名密码是否正确
- 数据库是否存在
- 防火墙是否阻止连接

### 问题2: 端口被占用

```bash
# 查看端口占用
lsof -i :4000
# 或
netstat -tulpn | grep 4000

# 修改 .env 中的 PORT
```

### 问题3: PM2 服务无法启动

```bash
# 查看详细错误
pm2 logs wx-we-love-api --err

# 检查环境变量
pm2 env 0
```

### 问题4: 微信小程序无法访问

**检查：**
- 域名是否在微信后台配置
- 是否使用 HTTPS（生产环境）
- 域名是否备案（国内服务器）
