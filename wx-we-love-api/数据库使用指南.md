# 📚 数据库使用指南（前端工程师版）

## 🎯 数据库是什么？

**简单理解**：数据库就像前端的 `localStorage` 或 `sessionStorage`，但更强大：
- ✅ 可以存储复杂的数据结构（类似 JSON）
- ✅ 可以建立数据之间的关系（类似对象引用）
- ✅ 可以快速查询和筛选数据
- ✅ 数据持久化保存（不会因为刷新而丢失）

**类比前端**：
```javascript
// 前端 localStorage（简单）
localStorage.setItem('user', JSON.stringify({ name: '小明' }))

// 数据库（强大）
// 可以存储多个用户，可以查询、筛选、排序等
```

## 🗄️ 这个项目使用的数据库类型

项目支持**两种数据库**，根据配置自动选择：

### 1️⃣ SQLite（开发环境 - 默认）

**特点**：
- 📦 **轻量级**：不需要单独安装数据库软件
- 🚀 **快速启动**：开箱即用，适合本地开发
- 💾 **文件存储**：数据保存在一个 `.db` 文件中
- ⚠️ **内存模式**：当前配置为内存模式，重启后数据会丢失

**使用场景**：
- ✅ 本地开发测试
- ✅ 快速原型开发
- ✅ 小型项目

**配置位置**：`src/config/database.js`
```javascript
// 如果没有配置 MySQL，自动使用 SQLite 内存数据库
new Sequelize({
  dialect: 'sqlite',
  storage: ':memory:',  // 内存模式（重启后数据丢失）
  // storage: './database.sqlite',  // 文件模式（数据持久化）
})
```

### 2️⃣ MySQL（生产环境 - 推荐）

**特点**：
- 🏢 **企业级**：功能强大，适合生产环境
- 👥 **多用户**：支持多个应用同时访问
- 🔒 **安全性高**：完善的权限管理
- 📈 **性能好**：处理大量数据时表现优秀

**使用场景**：
- ✅ 正式上线部署
- ✅ 需要多人协作
- ✅ 数据量较大

**配置位置**：`src/.env` 文件
```env
DB_HOST=localhost      # 数据库服务器地址
DB_PORT=3306          # 数据库端口（MySQL默认3306）
DB_NAME=we_love_db    # 数据库名称
DB_USER=root          # 数据库用户名
DB_PASSWORD=你的密码   # 数据库密码
```

## 📊 数据模型（类似 TypeScript 类型定义）

**理解方式**：数据模型就像前端的 TypeScript 接口定义，规定了数据的结构。

### 示例对比

**前端 TypeScript**：
```typescript
interface User {
  id: number
  name1: string
  name2: string
  loveDate: string
}
```

**后端数据模型**：
```javascript
const User = sequelize.define('User', {
  id: {
    type: DataTypes.INTEGER,
    primaryKey: true,
    autoIncrement: true  // 自动递增
  },
  name1: {
    type: DataTypes.STRING,
    allowNull: true  // 允许为空
  },
  // ...
})
```

### 项目中的所有数据模型

| 模型名称 | 作用 | 主要字段 |
|---------|------|---------|
| **User** | 用户信息 | 情侣名字、头像、恋爱日期、功能排序 |
| **Wishlist** | 心愿清单 | 内容、状态（pending/completed）、完成时间 |
| **DateRecord** | 约会记录 | 标题、日期、地点、描述、照片、评分 |
| **Anniversary** | 纪念日 | 标题、日期、类型、是否每年提醒 |
| **Note** | 记事本 | 标题、内容、心情、创建时间 |
| **PiggyBank** | 存钱罐 | 金额、类型（收入/支出）、描述 |
| **Menstrual** | 姨妈周期 | 开始日期、周期天数、备注 |

## 🛠️ 如何配置和使用

### 方式一：使用 SQLite（最简单，适合开发）

**步骤**：
1. **不需要任何配置**，直接运行即可
2. 数据会保存在内存中（重启后丢失）

```bash
cd wx-we-love-api
npm install
npm run dev
```

**注意**：如果想数据持久化，修改 `src/config/database.js`：
```javascript
// 改为文件存储模式
new Sequelize({
  dialect: 'sqlite',
  storage: './database.sqlite',  // 数据会保存在这个文件
  logging: false
})
```

### 方式二：使用 MySQL（推荐生产环境）

**步骤**：

#### 1. 安装 MySQL（如果还没安装）

**macOS**：
```bash
# 使用 Homebrew 安装
brew install mysql
brew services start mysql
```

**Windows**：
- 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
- 按照向导安装

**Linux**：
```bash
sudo apt-get install mysql-server  # Ubuntu/Debian
sudo yum install mysql-server      # CentOS/RHEL
```

#### 2. 创建数据库

```bash
# 登录 MySQL（首次登录可能没有密码）
mysql -u root -p

# 在 MySQL 命令行中执行
CREATE DATABASE we_love_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

#### 3. 配置环境变量

编辑 `src/.env` 文件：
```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=we_love_db
DB_USER=root
DB_PASSWORD=你的MySQL密码
```

#### 4. 启动服务

```bash
npm run dev
```

如果看到：
```
✅ Database connection established successfully
🚀 Server is running on port 4000
```
说明连接成功！

## 📝 Sequelize ORM 是什么？

**ORM** = Object-Relational Mapping（对象关系映射）

**简单理解**：就像前端的 `axios` 封装了 `fetch`，Sequelize 封装了数据库操作。

### 对比原生 SQL 和 Sequelize

**原生 SQL**（复杂）：
```sql
SELECT * FROM Users WHERE name1 = '小明' AND name2 = '小红';
```

**Sequelize**（简单，类似 JavaScript）：
```javascript
const users = await User.findAll({
  where: {
    name1: '小明',
    name2: '小红'
  }
})
```

### 常用 Sequelize 操作（类比前端）

| 操作 | Sequelize | 前端类比 |
|------|-----------|---------|
| **查询所有** | `User.findAll()` | `array.map()` |
| **查询单个** | `User.findOne()` | `array.find()` |
| **创建** | `User.create()` | `array.push()` |
| **更新** | `user.update()` | `object.property = value` |
| **删除** | `user.destroy()` | `array.splice()` |

## 🎯 实际使用示例

### 在路由中使用数据库（查看 `src/routes/user.js`）

```javascript
const { User } = require('../models');

// 获取用户信息（类似 GET 请求）
router.get('/info', async (req, res) => {
  try {
    // 查询数据库
    let user = await User.findOne();
    
    // 如果没有数据，创建一个默认用户
    if (!user) {
      user = await User.create({
        name1: '小明',
        name2: '小红',
        loveDate: '2024-01-01'
      });
    }
    
    // 返回数据（类似 res.json()）
    res.json({
      success: true,
      data: user
    });
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
});

// 更新用户信息（类似 POST/PUT 请求）
router.post('/info', async (req, res) => {
  try {
    let user = await User.findOne();
    
    if (!user) {
      user = await User.create(req.body);
    } else {
      await user.update(req.body);  // 更新数据
    }
    
    res.json({
      success: true,
      data: user
    });
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
});
```

## ⚠️ 常见问题

### Q1: 数据丢失了？
**A**: 如果使用 SQLite 内存模式（`:memory:`），重启服务后数据会丢失。改为文件模式或使用 MySQL。

### Q2: 如何备份数据？
**A**: 
- **SQLite**：复制 `.sqlite` 文件
- **MySQL**：使用 `mysqldump` 命令

### Q3: 数据库连接失败？
**A**: 检查：
1. MySQL 服务是否启动
2. `.env` 配置是否正确
3. 数据库是否已创建
4. 用户名密码是否正确

### Q4: 如何清空所有数据？
**A**: 
- **SQLite**：删除 `.sqlite` 文件，重启服务
- **MySQL**：在数据库中执行 `DROP DATABASE we_love_db;` 然后重新创建
