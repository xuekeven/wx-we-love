# 数据库常用命令（MySQL）

在服务器上进入 MySQL 后，先选库再查表。示例库名：`wx_we_love`。

## 登录

```bash
mysql -u root -p
```

## 查看有哪些库

```sql
SHOW DATABASES;
```

## 选库

```sql
USE wx_we_love;
```

## 查看当前库有哪些表

```sql
SHOW TABLES;
```

表名以 `SHOW TABLES` 输出为准（Linux 下可能区分大小写）。

## 查看表结构

```sql
DESCRIBE Users;
```

或：

```sql
SHOW CREATE TABLE Users\G
```

## 查看表数据（常用）

先看前几行，避免一次拉全表：

```sql
SELECT * FROM Users LIMIT 20;
```

## 统计行数

```sql
SELECT COUNT(*) FROM Users;
```

## 按条件查询

```sql
SELECT id, openId, currentName, isMatched, matchedUserId, loveDate
FROM Users
WHERE openId = 'xxx';
```

## 本项目可能涉及的业务表（示例）

```sql
SELECT * FROM Anniversaries LIMIT 20;
SELECT * FROM Menstruals LIMIT 20;
SELECT * FROM MoodDiaries LIMIT 20;
SELECT * FROM MoodDiaryComments LIMIT 20;
```

若某张表不存在，以 `SHOW TABLES` 结果为准。

## 退出

```sql
EXIT;
```

## 使用建议

- 数据量大时优先 `LIMIT` 或加 `WHERE`，避免无限制 `SELECT *`。
- 生产环境查询只读即可，删改前务必确认条件。
