# 📊 数据模型说明（前端视角）

## 🎯 理解方式

把数据模型想象成前端的 **TypeScript 接口** 或 **JSON Schema**，它们定义了数据的结构和类型。

---

## 📋 所有数据模型一览

### 1. User（用户表）- 存储情侣基本信息

**作用**：存储一对情侣的基本信息

**字段说明**：
```typescript
interface User {
  id: number              // 主键，自动递增
  loveDate: string        // 恋爱开始日期，格式：'2024-01-01'
  name1: string          // 第一个人的名字
  name2: string          // 第二个人的名字
  avatar1: string        // 第一个人的头像URL
  avatar2: string        // 第二个人的头像URL
  functionOrder: {       // 功能排序配置（JSON格式）
    '1': number,         // 功能1的排序
    '2': number,         // 功能2的排序
    // ...
  }
}
```

**前端对应**：首页显示的情侣信息

---

### 2. Anniversary（纪念日表）

**作用**：记录重要的纪念日

**字段说明**：
```typescript
interface Anniversary {
  id: string             // UUID
  title: string          // 纪念日名称，如"在一起100天"
  date: string           // 日期，格式：'2024-04-10'
  type: string           // 类型，如'custom'（自定义）
  isYearly: boolean      // 是否每年重复
  reminder: boolean      // 是否提醒
}
```

**前端对应**：纪念日页面

**示例数据**：
```json
{
  "id": "ann-001",
  "title": "在一起100天",
  "date": "2024-04-10",
  "type": "custom",
  "isYearly": false,
  "reminder": true
}
```

---

### 3. Menstrual（姨妈周期表）

**作用**：记录生理期信息

**字段说明**：
```typescript
interface Menstrual {
  id: string             // UUID
  startDate: string      // 开始日期
  cycleDays: number      // 周期天数
  periodDays: number     // 经期天数
  note: string          // 备注
}
```

**前端对应**：姨妈周期页面

## 💡 前端如何使用这些数据

### 示例：获取纪念日列表

**前端代码**：
```typescript
// 使用 request 工具函数
import { get } from '@/utils/request'

// 获取纪念日列表
const fetchAnniversaries = async () => {
  const response = await get('/api/anniversaries')
  if (response.success) {
    const anniversaries: Anniversary[] = response.data
    return anniversaries
  }
}
```

**后端返回格式**：
```json
{
  "success": true,
  "data": [
    {
      "id": "ann-001",
      "title": "在一起100天",
      "date": "2024-04-10",
      "type": "custom",
      "isYearly": false,
      "reminder": true
    }
  ]
}
```

## 🎨 数据类型对照表

| Sequelize 类型 | TypeScript 类型 | 说明 |
|---------------|----------------|------|
| `DataTypes.INTEGER` | `number` | 整数 |
| `DataTypes.STRING` | `string` | 字符串 |
| `DataTypes.TEXT` | `string` | 长文本 |
| `DataTypes.DATEONLY` | `string` | 日期（'YYYY-MM-DD'） |
| `DataTypes.DATE` | `Date` 或 `string` | 日期时间 |
| `DataTypes.BOOLEAN` | `boolean` | 布尔值 |
| `DataTypes.JSON` | `object` | JSON对象 |
| `DataTypes.ENUM` | `'value1' \| 'value2'` | 枚举值 |
| `DataTypes.UUID` | `string` | UUID字符串 |

## 📝 总结

1. **数据模型** = 前端的 TypeScript 接口定义
2. **Sequelize** = 操作数据库的工具（类似 axios）
3. **数据库** = 存储数据的地方（类似 localStorage，但更强大）
4. **每个表** = 一个功能模块的数据存储

**开发流程**：
1. 后端定义数据模型（已定义好）
2. 后端创建 API 路由（已创建好）
3. 前端调用 API 获取数据
4. 前端展示数据

就是这么简单！🎉
