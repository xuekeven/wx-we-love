# 📊 数据模型说明（前端视角）

## 🎯 理解方式

把数据模型想象成前端的 **TypeScript 接口** 或 **JSON Schema**，它们定义了数据的结构和类型。

---

## 📋 所有数据模型一览

### 1. User（用户表）- 存储情侣基本信息

**作用**：存储一对情侣的基本信息

**字段说明**：
```typescript
interface User {
  id: number              // 主键，自动递增
  loveDate: string        // 恋爱开始日期，格式：'2024-01-01'
  name1: string          // 第一个人的名字
  name2: string          // 第二个人的名字
  avatar1: string        // 第一个人的头像URL
  avatar2: string        // 第二个人的头像URL
  functionOrder: {       // 功能排序配置（JSON格式）
    '1': number,         // 功能1的排序
    '2': number,         // 功能2的排序
    // ...
  }
}
```

**前端对应**：首页显示的情侣信息

---

### 2. Wishlist（心愿清单表）

**作用**：记录想一起完成的心愿

**字段说明**：
```typescript
interface Wishlist {
  id: string             // UUID格式的唯一ID
  content: string        // 心愿内容，如"一起去日本旅行"
  status: 'pending' | 'completed'  // 状态：待完成 | 已完成
  completedAt: Date | null  // 完成时间（如果已完成）
}
```

**前端对应**：心愿清单页面

**示例数据**：
```json
{
  "id": "abc-123-def",
  "content": "一起去日本看樱花",
  "status": "pending",
  "completedAt": null
}
```

---

### 3. DateRecord（约会记录表）

**作用**：记录每次约会的详细信息

**字段说明**：
```typescript
interface DateRecord {
  id: string             // UUID
  title: string          // 约会标题，如"第一次看电影"
  date: string           // 约会日期，格式：'2024-01-15'
  location: string       // 约会地点
  description: string    // 详细描述
  photos: string[]       // 照片URL数组
  rating: number         // 评分（1-5分）
}
```

**前端对应**：约会记录页面

**示例数据**：
```json
{
  "id": "xyz-789-ghi",
  "title": "第一次看电影",
  "date": "2024-01-15",
  "location": "万达影城",
  "description": "看了《你的名字》，很感动",
  "photos": ["https://example.com/photo1.jpg"],
  "rating": 5
}
```

## 🔗 数据关系（当前版本）

## 💡 前端如何使用这些数据

### 示例：获取心愿清单

**前端代码**：
```typescript
// 使用 request 工具函数
import { get } from '@/utils/request'

// 获取心愿列表
const fetchWishlist = async () => {
  const response = await get('/api/wishlist')
  if (response.success) {
    const wishlist: Wishlist[] = response.data
    // wishlist 就是符合 Wishlist 接口的数据数组
    return wishlist
  }
}
```

**后端返回格式**：
```json
{
  "success": true,
  "data": [
    {
      "id": "abc-123",
      "content": "一起去日本看樱花",
      "status": "pending",
      "completedAt": null
    },
    {
      "id": "def-456",
      "content": "一起学做菜",
      "status": "completed",
      "completedAt": "2024-01-20T10:00:00Z"
    }
  ]
}
```

## 🎨 数据类型对照表

| Sequelize 类型 | TypeScript 类型 | 说明 |
|---------------|----------------|------|
| `DataTypes.INTEGER` | `number` | 整数 |
| `DataTypes.STRING` | `string` | 字符串 |
| `DataTypes.TEXT` | `string` | 长文本 |
| `DataTypes.DATEONLY` | `string` | 日期（'YYYY-MM-DD'） |
| `DataTypes.DATE` | `Date` 或 `string` | 日期时间 |
| `DataTypes.BOOLEAN` | `boolean` | 布尔值 |
| `DataTypes.JSON` | `object` | JSON对象 |
| `DataTypes.ENUM` | `'value1' \| 'value2'` | 枚举值 |
| `DataTypes.UUID` | `string` | UUID字符串 |

## 📝 总结

1. **数据模型** = 前端的 TypeScript 接口定义
2. **Sequelize** = 操作数据库的工具（类似 axios）
3. **数据库** = 存储数据的地方（类似 localStorage，但更强大）
4. **每个表** = 一个功能模块的数据存储

**开发流程**：
1. 后端定义数据模型（已定义好）
2. 后端创建 API 路由（已创建好）
3. 前端调用 API 获取数据
4. 前端展示数据

就是这么简单！🎉
