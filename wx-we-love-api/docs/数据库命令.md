# 数据库常用命令（Docker MySQL）

本项目生产环境使用 Docker 方式运行 MySQL。当前常用信息：

- MySQL 容器名：`mysql-server`
- 数据库名：`wx_we_love`
- 常用登录用户：`root`

如果容器名或库名变化，以服务器实际配置为准。

## 1. 查看 MySQL 容器

```bash
docker ps
```

确认列表里有 MySQL 容器，例如：

```text
mysql-server
```

如果容器没有运行，可以查看全部容器：

```bash
docker ps -a
```

## 2. 进入 MySQL 命令行

推荐直接进入指定数据库：

```bash
docker exec -it mysql-server mysql -u root -p wx_we_love
```

输入 MySQL root 密码后，就会进入 `wx_we_love` 数据库。

也可以先进入 MySQL，再手动选库：

```bash
docker exec -it mysql-server mysql -u root -p
```

```sql
USE wx_we_love;
```

## 3. 查看库和表

查看所有数据库：

```sql
SHOW DATABASES;
```

查看当前数据库：

```sql
SELECT DATABASE();
```

查看当前库有哪些表：

```sql
SHOW TABLES;
```

表名以 `SHOW TABLES` 输出为准。Linux 下 MySQL 表名可能区分大小写。

## 4. 查看表结构

查看字段：

```sql
DESCRIBE Users;
```

查看建表语句：

```sql
SHOW CREATE TABLE Users\G
```

本项目常见业务表：

```sql
DESCRIBE Users;
DESCRIBE Anniversaries;
DESCRIBE Menstruals;
DESCRIBE MoodDiaries;
DESCRIBE MoodDiaryComments;
```

若某张表不存在，以 `SHOW TABLES` 结果为准。

## 5. 常用只读查询

生产环境优先使用只读查询。先加 `LIMIT` 看少量数据，避免一次拉全表。

查看用户：

```sql
SELECT id, openId, currentName, matchedUserId, isMatched, loveDate
FROM Users
ORDER BY id DESC
LIMIT 20;
```

查看纪念日：

```sql
SELECT id, userId, title, date, type, createdAt
FROM Anniversaries
ORDER BY id DESC
LIMIT 20;
```

查看经期记录：

```sql
SELECT id, userId, startDate, endDate, cycleLength, symptoms, createdAt
FROM Menstruals
ORDER BY id DESC
LIMIT 20;
```

查看心情日记：

```sql
SELECT id, userId, date, moodId, createdAt
FROM MoodDiaries
ORDER BY id DESC
LIMIT 20;
```

查看心情日记评论：

```sql
SELECT id, diaryId, userId, content, createdAt
FROM MoodDiaryComments
ORDER BY id DESC
LIMIT 20;
```


## 7. 按用户排查数据

先找到用户：

```sql
SELECT id, openId, currentName, matchedUserId, isMatched
FROM Users
WHERE currentName LIKE '%名字%'
LIMIT 20;
```

按用户 `id` 查询纪念日：

```sql
SELECT *
FROM Anniversaries
WHERE userId = 1
ORDER BY date DESC
LIMIT 50;
```

按用户 `id` 查询经期记录：

```sql
SELECT *
FROM Menstruals
WHERE userId = 1
ORDER BY startDate DESC
LIMIT 50;
```

按用户 `id` 查询心情日记：

```sql
SELECT *
FROM MoodDiaries
WHERE userId = 1
ORDER BY date DESC
LIMIT 50;
```

## 8. 检查旧数据隔离字段

本项目曾为 `Anniversaries` 和 `Menstruals` 增加 `userId` 字段。发新版后如果旧数据没有显示，可以先检查是否存在 `userId IS NULL` 的历史数据。

```sql
SELECT COUNT(*) AS null_user_anniversaries
FROM Anniversaries
WHERE userId IS NULL;
```

```sql
SELECT COUNT(*) AS null_user_menstruals
FROM Menstruals
WHERE userId IS NULL;
```

如果存在旧数据，需要先确认这些数据应该归属哪个用户，再谨慎补 `userId`。不要在未确认归属前批量更新。

## 9. 修改数据前的安全步骤

生产环境做 `UPDATE` / `DELETE` 前，先完成三步：

1. 备份数据库，见 [数据备份.md](./数据备份.md)
2. 先用同样的 `WHERE` 条件执行 `SELECT`
3. 确认影响范围后再执行修改

示例：先查再改。

```sql
SELECT id, userId, title, date
FROM Anniversaries
WHERE id = 1;
```

确认无误后再执行：

```sql
UPDATE Anniversaries
SET userId = 1
WHERE id = 1;
```

删除同理，先查：

```sql
SELECT *
FROM Menstruals
WHERE id = 1;
```

确认无误后再删：

```sql
DELETE FROM Menstruals
WHERE id = 1;
```
